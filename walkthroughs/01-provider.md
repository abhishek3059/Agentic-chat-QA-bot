# Choose your LLM provider

QA Assistant works with any OpenAI-compatible endpoint — no code changes needed
to switch.

1. Run [QA Assistant: Configure LLM Provider](command:contextQa.configureProvider)
   and pick **OpenAI**, **OpenRouter**, **DeepSeek**, **Ollama (local)**, or **Custom**.
2. Using Ollama, LM Studio, or vLLM? Choose **Custom** and set
   `contextQa.apiBaseUrl` in Settings (e.g. `http://localhost:11434/v1`).

Next: save your API key.
