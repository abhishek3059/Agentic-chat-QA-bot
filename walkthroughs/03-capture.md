# Capture an AI response

Scope the console to any agent response you want to interrogate:

- **Clipboard:** copy the response, then press `Ctrl+Alt+Q` (`Cmd+Alt+Q` on Mac),
  or run [QA Assistant: Capture from Clipboard](command:contextQa.captureClipboard).
- **Editor selection:** right-click highlighted text → **QA Assistant: Ask About Selection**.
- **Manual:** click ✏️ in the sidebar and paste directly.

The sidebar opens showing character/token stats for the captured context.
