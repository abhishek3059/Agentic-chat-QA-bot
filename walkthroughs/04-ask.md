# Ask your first question

With context captured, the input box switches to **Ask anything...** mode.

1. Try *"Explain this simpler"* — the answer streams back grounded in your
   captured response, with follow-up suggestion chips underneath.
2. Off-topic questions get a plain disclosure instead of a silent hallucination.
3. Click the **model name** in the sidebar footer to browse your provider's live
   model list — search to narrow it, ☆ to pin favorites.

Tip: open the console anytime with [QA Assistant: Open Agent Console](command:contextQa.openPanel).
You're set — check the Marketplace page's Changelog tab for what's new in each release.
