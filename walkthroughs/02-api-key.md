# Save your API key

Your key is stored in VS Code's encrypted **SecretStorage** — it never touches
`settings.json`, logs, or disk.

1. Run [QA Assistant: Set LLM API Key](command:contextQa.setApiKey).
2. Paste your provider's key and press Enter. The 🔑 dot in the sidebar turns
   green when a key is saved.

No key needed for local Ollama.
