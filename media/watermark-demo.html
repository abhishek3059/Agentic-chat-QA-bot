What port does Redis run on?
Redis listens on 6379 with a 60-second sliding TTL window.
Explain the sliding window simply.
Think of it as a guest list with timestamps: every request signs in, and the bouncer only counts signatures from the last 60 seconds.
Show me the isAllowed code.
tx.zRemRangeByScore(key, 0, clearBefore); tx.zAdd(key, ...); tx.expire(key, windowSec);
What are the edge cases?
Clock skew between nodes, and bursts exactly at the window boundary counting twice.
